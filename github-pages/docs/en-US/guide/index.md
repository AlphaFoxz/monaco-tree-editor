# Introduction (Documentation v1.2.0)

## What this library does

- [x] Provides a VSCode-style file tree
- [x] Vue events using async API
- [x] Provides a floating global message hook

## Prerequisites

- [Node.js v18.18+](https://nodejs.org/en)
- [vue3 v3.5.12+](https://vuejs.org/){target="\_blank"} or [nuxt3 v3.0+](https://nuxt.com/){target="\_blank"}
- [monaco-editor v0.52.2+](https://microsoft.github.io/monaco-editor/){target="\_blank"}
- [Recommended] [pnpm package manager](https://pnpm.io/){target="\_blank"}
