# Introduction (Documentation v1.2.0)

## What this library does

- [x] Provides a VSCode-style file tree
- [x] Vue events using async API
- [x] Provides a floating global message hook

## Prerequisites

- [Node.js v18.18+](https://nodejs.org/en)
- <a href="https://vuejs.org/" target="_blank">vue3 v3.5.12+</a> or <a href="https://nuxt.com/" target="_blank">nuxt3 v3.0+</a>
- <a href="https://microsoft.github.io/monaco-editor/" target="_blank">monaco-editor v0.52.2+</a>
- [Recommended] <a href="https://pnpm.io/" target="_blank">pnpm package manager</a>
